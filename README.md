# ABC Executive Summary & Profitability Dashboard

## Project Overview
An interactive Microsoft Excel dashboard designed to analyze sales performance and profitability across countries, regions, product categories, sales channels, and quarters.

## Key Features
- **KPI Cards:** Total Revenue, Total Gross Profit, Gross Profit Margin, Total Units Sold, Total Orders, and COGS.
- **Monthly Performance:** Revenue and gross profit trends throughout the year.
- **Country Analysis:** Top 5 countries ranked by revenue.
- **Sales Channel Analysis:** Revenue share by Corporate and Marketplace channels.
- **Regional Comparison:** Revenue distribution across European regions.
- **Geographical Visualization:** Country-wise revenue map chart.
- **Interactive Filters:** Slicers for product category, country, and quarter.

## Tools & Techniques
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Interactive Slicers
- KPI Reporting and Data Visualization
- Sales and Profitability Analysis

## Objective
To transform sales data into an interactive dashboard that helps users monitor key business metrics, identify performance trends, compare regional results, and make data-driven decisions.
